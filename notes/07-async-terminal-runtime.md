# 07｜异步终端与运行时协调

> 对应源码：`entry/main.py`  
> 辅助源码：`cyberclaw/core/bus.py`、`cyberclaw/core/heartbeat.py`、`examples/basic_usage.py`

## 一、本课核心内容

### 1. 事件循环与协程

`main()` 通过：

```python
asyncio.run(async_main())
```

创建事件循环并运行主协程。

协程在遇到 `await` 时可以暂停，让事件循环调度其他就绪协程。它是协作式并发，不等于为每个任务创建一个线程。

### 2. Task

调用协程函数只产生协程对象；执行：

```python
asyncio.create_task(coro())
```

才会把它包装为已经交给事件循环调度的 Task。

正式入口主要包含：

```text
agent_worker
heartbeat_worker
user_input_loop
└── redraw_timer
```

### 3. 共享队列

全局 `asyncio.Queue` 连接两个生产者和一个消费者：

```text
用户输入 ─────┐
              ├→ task_queue → agent_worker
心跳到期 ─────┘
```

两种消息都只是字符串，消费者统一包装成 `HumanMessage`。

### 4. 单 Agent worker

只有一个消费者，因此同一 `thread_id` 的消息按顺序执行，避免同时更新同一图状态。

代价是：

- 一个慢请求会阻塞后续请求；
- 用户和心跳任务共用等待队列；
- 队列无容量上限，缺少背压。

### 5. 图事件流

```python
async for event in app.astream(
    ...,
    stream_mode="updates"
):
```

会依次得到 Agent 节点和 Tools 节点完成后的增量状态，因此终端能先显示工具调用，再显示最终回答。

它是节点级流式更新，不是逐 Token 输出。

### 6. 异步外壳与同步内部

正式入口调用 `app.astream()`，但 `agent_node()` 内部使用：

```python
llm_with_tools.invoke(...)
```

而不是 `ainvoke()`。所以只能确认图事件以异步接口消费，不能仅凭这一点认定整个模型调用链都是原生异步。同步节点是否在线程中运行取决于 LangGraph 的实现。

### 7. 异步终端

`prompt_async()` 在等待键盘时让出事件循环；`redraw_timer()` 每隔约 80 ms 使提示界面重绘；`patch_stdout()` 减少后台输出破坏当前输入行的问题。

### 8. 队列完成语义

```text
put()       → 未完成计数 +1
task_done() → 未完成计数 -1
join()      → 等待计数归零
```

`join()` 等待的是所有已入队项目都被标记完成，不只是等待队列暂时为空。

### 9. 退出边界

当前代码在输入循环结束后：

```python
await task_queue.join()
worker.cancel()
heartbeat_worker.cancel()
```

存在几个不足：

- `task_done()` 没有放在覆盖单项处理的 `finally`；
- `cancel()` 后没有 `await` Task 完成；
- 缺少统一 `try/finally` 收尾；
- worker 处理 `/exit` 后可能先退出，而心跳仍可能继续入队，导致 `join()` 等不到新项目完成。

### 10. 同步示例不是正式运行时

`examples/basic_usage.py` 没有异步输入、心跳、队列、checkpoint 和终端协调。它只适合观察图节点更新，而且没有把 AI/Tool 消息合并回下一轮本地 state，因此多轮历史并不完整。

## 二、自测题与参考答案

### 1. 什么是事件循环？

**参考答案：**

它是 `asyncio` 的协作式调度器。某个协程运行到 `await` 并等待未完成操作时，事件循环可以去运行其他就绪协程，之后再恢复原协程。

### 2. 调用一个 `async def` 函数后会立刻执行吗？

**参考答案：**

不会像普通函数一样直接执行完成。调用会产生协程对象，需要被 `await`，或用 `create_task()` 安排到事件循环中运行。

### 3. 协程和 Task 有什么区别？

**参考答案：**

协程对象描述一段可暂停工作；Task 是协程被事件循环安排执行后的运行载体，记录执行、完成、异常和取消状态。

### 4. `await` 是否会启动一个新线程？

**参考答案：**

不会。`await` 通常让当前协程暂停并把控制权交回事件循环。只有显式使用线程池、`to_thread()`，或框架内部转交线程时，才涉及工作线程。

### 5. `task_queue` 解决了什么问题？

**参考答案：**

它把消息生产者和 Agent 消费者解耦。用户输入和心跳只负责入队，Agent worker 只负责按顺序取出并执行，不需要互相知道具体实现。

### 6. 为什么用户输入和心跳都变成 `HumanMessage`？

**参考答案：**

worker 对所有队列字符串采用同一包装逻辑。当前设计没有专门的系统事件类型，所以到期提醒以自然语言用户消息的形式重新注入 Agent。

### 7. 为什么只有一个 `agent_worker()`？

**参考答案：**

单消费者让一个会话中的输入串行，降低两个请求同时读写同一 checkpoint 的竞争。不过这也牺牲了并发吞吐，慢请求会阻塞后续任务。

### 8. `stream_mode="updates"` 表示什么？

**参考答案：**

图每个节点执行后产生增量状态事件。终端可以分别观察 Agent 的工具调用、Tools 的结果和 Agent 的最终回答，而不是只取得图结束后的完整状态。

### 9. 当前为什么不是逐 Token 流式输出？

**参考答案：**

终端接收的是节点更新；`agent_node()` 使用同步 `invoke()` 得到完整 AIMessage 后才返回。因此展示粒度是节点，而不是模型生成的每个 Token。

### 10. `prompt_async()` 有什么意义？

**参考答案：**

等待用户键盘输入期间不会一直占用事件循环，心跳、Agent worker 和 Spinner 刷新仍有机会运行。

### 11. `patch_stdout()` 是否保证业务并发安全？

**参考答案：**

不保证。它主要让后台打印与正在编辑的提示行协调，解决终端显示问题，不负责数据库、队列或共享业务状态的一致性。

### 12. `queue.join()` 为什么可能一直等待？

**参考答案：**

只要某个入队项目没有对应的 `task_done()`，未完成计数就不会归零。worker 异常退出、取消时遗漏 `task_done()`，或 worker 退出后心跳又入队，都可能造成这种情况。

### 13. 为什么 `app.astream()` 不代表内部全部非阻塞？

**参考答案：**

异步流只描述外层消费接口。Agent 节点内部仍调用同步 `llm_with_tools.invoke()`；同步执行是否被框架放到线程，必须看 LangGraph 的实现，不能从函数名直接推断。

### 14. `asyncio.sleep()` 和 `time.sleep()` 有什么区别？

**参考答案：**

`asyncio.sleep()` 暂停当前协程并让事件循环运行其他任务；`time.sleep()` 阻塞当前线程。在事件循环线程中使用后者会阻止其他协程获得执行机会。

### 15. 为什么退出时仅调用 `cancel()` 不够完整？

**参考答案：**

`cancel()` 是发出取消请求，不代表 Task 已经完成清理。通常还应 `await` 被取消的 Task，处理 `CancelledError`，并在 `finally` 中释放资源。

## 三、面试追问与回答思路

### 1. 你会怎样重构关闭流程？

**回答思路：**

先停止用户和心跳生产者，再用明确 sentinel 通知消费者；根据策略处理或丢弃剩余队列；将 `task_done()` 放进 `finally`；使用 `try/finally` 取消并 `await` 所有 Task；最后关闭 checkpoint 和终端资源。

### 2. 多用户服务怎样扩展这个队列模型？

**回答思路：**

不能用单个全局无界队列。可以按会话串行、跨会话并行，设置总量和用户级容量限制，支持请求 ID、取消、超时、优先级和公平调度，并明确 checkpoint 的并发控制。

### 3. 怎样把模型调用改成更明确的异步实现？

**回答思路：**

把 Agent 节点改成异步函数，使用 `await llm.ainvoke()`，异步工具使用 `arun/ainvoke`，同步阻塞工具通过受控线程池或进程池执行。同时检查底层 HTTP 客户端、数据库和回调是否真正异步。

### 4. 怎样实现逐 Token 输出？

**回答思路：**

使用支持 streaming 的模型异步接口，订阅模型 Token 事件，并把节点事件和 Token 事件区分开。终端层还要处理工具调用期间的状态切换、取消、错误和输出重绘。

### 5. 为什么“异步”不一定让单次请求更快？

**回答思路：**

异步主要提升等待期间的并发利用率和交互响应性。一次模型请求的网络延迟不会因为使用 `await` 自动缩短；它让线程在等待时能处理其他工作。

### 6. 简历怎样准确描述运行时改造？

**回答思路：**

可以写“基于 asyncio 设计按会话串行、跨会话并发的 Agent 调度，补充背压、取消和优雅关闭”。需要有实现、压力数据和故障测试，不能只因为入口存在 `asyncio.run()` 就写“高并发异步架构”。
